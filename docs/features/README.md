# docs/features

One file per screen; every file follows `_template.md`.

| File             | Screens                                                        |
| ---------------- | -------------------------------------------------------------- |
| `auth.md`        | login, sign up, email callback, session                        |
| `home.md`        | the home tab                                                   |
| `explore.md`     | the explore tab                                                |
| `genre.md`       | a genre's playlists                                            |
| `album.md`       | an album, and the detail screen base                           |
| `artist.md`      | an artist                                                      |
| `playlist.md`    | a playlist (own, liked, genre)                                 |
| `search.md`      | the search tab                                                 |
| `library.md`     | the library tab and the create-playlist sheet                  |
| `player.md`      | the mini player and the player                                 |
| `tabs.md`        | the tab navigator                                              |
| `likes.md`       | the likes mirror (no screen)                                   |
| `bug-reports.md` | the report form and My reports                                 |
| `track-menu.md`  | the heart, the track menu, the playlist picker and the credits |
