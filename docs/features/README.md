# docs/features

One file per screen; every file follows `_template.md`.

| File         | Screens                                    |
| ------------ | ------------------------------------------ |
| `auth.md`    | login, sign up, email callback, session    |
| `home.md`    | the home tab                               |
| `explore.md` | the explore tab                            |
| `genre.md`   | a genre's playlists                        |
| `tabs.md`    | the tab navigator and the placeholder tabs |
